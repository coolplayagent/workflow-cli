# 显式有序补偿

补偿是声明的写任务，与主操作一样使用持久化意图、提供方查询、重试预算和租约隔离。流程选择业务分支，
运行时检查原操作是否可逆，以及依赖操作是否已先处理。取消不会自动选中补偿分支或撤销提供方资源。

## 定义与接纳

写描述符可声明 `compensation: {id, version}`，补偿能力必须是冻结 bundle 中的写能力。
`irreversible: true` 禁止声明补偿；默认 false 保持兼容，但没有 compensator 声明时并不保证可逆。

每个操作绑定可包含：

- `depends_on`：同一流程 frame 内最多 128 个不同的受管理节点 ID。
- `compensates`：此任务调用其声明 compensator 的原任务；每个原任务在定义中最多一个补偿任务。

编译拒绝缺失、自身、后置或可绕过前提、能力版本不匹配、补偿的补偿、不可逆原操作及相互矛盾的逆序。
声明前提必须位于到达依赖节点的每条路径之前。子流程/循环 frame 保持独立具体实例，不支持跨 frame
补偿依赖。

首次接纳时，store 把前提 operation key 和原操作的**真实 Applied 回执**冻结进意图。补偿 key 根据
原 operation key、补偿 slot 和准确补偿版本求摘要，在重试和所有权变更中稳定。输入、原资源、提供方
回执、目标与策略都绑定在意图摘要中。

每次接纳写入及回放都检查业务依赖图。前提必须 Applied 且不处于补偿中或已补偿。撤销原操作前，所有
传递性主依赖必须确认未应用（Failed/Cancelled），或已有自己的已完成补偿。进行中、未知和手工未解决
操作不能假定不存在。开始补偿也阻止后来的主写依赖该原操作。

Applied 补偿原子标记原操作 `compensated_by`，提交任务结果并放行后继。恢复不调用提供方。提供方已提交
但本地缺回执时走普通的先查询核对路径；已完成补偿不重复执行。

## 失败与人工接管

确认未产生效果的暂时补偿失败只在原幂等、次数和时间边界内重试。永久/权限/业务拒绝，或全部写确认
未应用后预算耗尽，产生 `needs_attention`，内核任务保持 Reconciling。先前未知写即使后来调用被拒绝，
仍然未知；重启不重置预算。

检查 `run effects` 和执行历史。未知结果与已知失败补偿都使 `drive-effects` 返回 `effect_uncertain`，
账本区分具体情况。可信本地操作员可执行有权清理，再以 `effect-resolve` 提交真实回执，保留稳定
resolution ID、actor 注释、reason 和 evidence；不会增加自动调用额度。准确重复解决幂等，改内容冲突。
Actor 注释不是认证身份。

`confirmed_not_applied` 取消补偿任务，但不把原操作标记为已补偿。它是“清理未发生”的审计确认，
不是成功回滚。应查看原回执和 `compensated_by`，仅凭运行 cancelled 不能证明全部外部资源已删除。

## 可执行示例与证据

`examples/runs/effect-compensation.json` 声明环境创建、部署及绑定两个资源 ID 的等待。批准保留资源，
拒绝/超时先删除部署再删除环境。测试等待为 100 逻辑毫秒；真实运行使用预期 ID、起始时间和经过评审的
超时。测试回调 source 明确表示模拟决策，不是实际人工审批。

SQLite 适配器测试在独立提供方数据库修改资源，外键禁止先删环境后删部署。覆盖暂时重试、补偿之间重开、
永久权限失败与真实手工清理、批准/拒绝/超时/取消分支，以及第二次提供方删除已提交但本地回执未提交时
杀死 worker。查询恢复完成撤销，每个 compensator 恰一次自动写，原删除不重复。纯账本测试拒绝错误
顺序、替换原回执、未解决依赖、迟到新依赖及逆转不可逆操作，账本状态保持不变。

Schema 9 引入这些语义，schema 10 增加[备份恢复](backup-recovery.md)保护。显式 v8→v9 迁移通过真实
旧二进制验证：暂停中的 pending Inbox、lease/attempt 历史和 prepared 操作意图在 CLI 边界字节等价；
v8 拒绝升级后的库。迁移测试不分发该 prepared 意图；迁移不等于备份/恢复。

本章描述可信本地接纳和有界测试下的显式分支补偿。[远程操作验收](remote-effects.md)增加认证共享分发
与完整 R05 矩阵，[审批验收](approval-acceptance.md)说明人工权限。任意任务失败回滚和生产提供方保证
不属于这些测试的结论。
